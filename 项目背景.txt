================================================================
  暗网追凶 - 深度网页解谜游戏 · 项目背景
================================================================

【项目概况】
- 项目名称：暗网追凶 - 论坛推理版（Detective Web Game）
- 游戏类型：沉浸式网页解谜 / 侦探推理
- 玩法形态：模拟浏览器 + 论坛搜证 + 线索板 + 嫌疑人审讯 + 推理结案
- 源码组织（v2.2 重构后）：
  · shared/src          —— 游戏逻辑单一真源（17 个页面 + 数据层 + 状态 + 通用组件）
  · web/app             —— 桌面端外壳：入口 + 地址栏/书签栏
  · h5/app              —— 移动端外壳：入口 + 顶部导航/底部 TabBar（桌面打开居中 480px）
  · scripts/            —— 线索可达性自检、通关仿真
  · 根 package.json     —— npm workspaces，统一 dev/build/verify 脚本
  重构前两端各自存有一份 4400 行的复制源码，现只保留唯一一份，外壳之外无任何重复。
- 技术栈：React 19 + TypeScript 6 + Vite 8 + Tailwind CSS 3 + React Router 7 + Zustand 5
- 构建方式：vite-plugin-singlefile 打包为单 HTML 文件，JS/CSS 全内联，零外部依赖
- 路由方案：HashRouter（兼容 file:// 本地直开与 GitHub Pages 部署）
- 质量门槛：npm run verify = lint + 全量类型检查 + 线索可达性 + 通关仿真 + 双端构建
- 在线地址：https://quanzhaobo.github.io/detective-web-game/ （部署的是 H5 单文件版）
- 本地直开：双击 dist/index.html 即可游玩，无需服务器、无需联网
- 最后更新：2026-10-03

================================================================
  一、游戏背景
================================================================

是关于一个连环女性碎尸抛尸案，3名受害者均来自外地务工女性，失踪前均现身城郊的一家连锁酒店，酒店有无死角监控。尸块均被抛到环城高速上不同匝道上的的绿化带，尸块包裹物为全新黑色加厚垃圾袋加透明保鲜膜，垃圾袋和保鲜膜没有指纹。

案发城市为虚构的"鹤城"。玩家以普通推理爱好者身份进入游戏，通过模拟浏览器中的搜索引擎、论坛、新闻网站、本地生活平台搜集公开信息，逐步发现案件线索，后被吸纳进入"专案组工作台"，调阅勘查记录、法医报告、监控分析、心理侧写等内部材料，审讯四名嫌疑人，最终在推理室做出唯一正确的判断。

  二、游戏线索
================================================================

勘查核心线索如下：

① 抛尸现场提取到42码男士运动鞋印（橡胶底，纹线有泥沙+微量山茶花粉，磨损特征符合常年驾车踩离合刹车），及一枚残缺混合指纹（含男性 DNA+女性DNA，女性DNA与3号受害人完全匹配，男性 DNA 未录入库）；

② 尸检：死者均为机械性窒息死亡，死后12h 内被分尸，分尸工具为家用菜刀+美工刀，切口整齐、关节分离精准，尸块皮肤有微量75%医用酒精+薄荷味口罩熔喷布纤维，指甲缝检出男性表皮组织（与混合指纹男性 DNA一致）+南方红壤土壤颗粒；

③ 物证溯源：垃圾袋/保鲜膜为本地批发市场流通款，花粉仅本市南郊山茶种植园独有；酒店监控显示，受害人失踪前均与一名操本地口音、戴黑色薄荷口罩、身高178cm左右的男性同行，该男性全程未摘口罩，离开时驾驶一辆深色SUV，监控仅拍到车尾无牌照；

④ 犯罪心理侧写：凶手反侦察能力极强，抛尸路线避开所有天网，分尸手法冷静且具备基础解剖常识，无性侵行为，对受害人无怜悯，作案周期固定为每18天1起。

结合法医物证、现场勘查、犯罪心理、侦查学逻辑，下列关于凶手的身份与作案特征判定，

A. 凶手为本地男性，职业是南郊山茶种植园货车司机，惯用左手，SUV为本地牌照，因性

B. 凶手为南方籍入赘本地的男性，职业是基层医务工作者/兽医，惯用右手，SUV 为外地套

================================================================
  四、玩家视角 · 游戏背景介绍
================================================================

【深夜，鹤城】

凌晨一点，你躺在床上刷手机。

屏幕的光映在脸上，拇指无意识地划着"清风推理论坛"的帖子。
你是这个论坛的老用户了——ID 叫什么来着？无所谓，这里没人
在意你是谁。大家只关心一件事：鹤城最近不太平。

三个月，三个女人。

她们都是从外地来鹤城打工的，年轻，独自租住，在这座城市里
没什么根基。失踪前，有人在城郊那家如家快捷酒店见过她们。
再后来，她们出现在环城高速的匝道绿化带里——被分装在黑色
加厚垃圾袋中，外面缠着一层又一层透明保鲜膜，像什么见不得
光的货物，被随手丢弃在路边的灌木丛里。

论坛炸了。

有人贴出了现场照片打码版，有人分析抛尸路线，有人赌咒发誓
说自己案发当晚在高速口看到过一辆没挂牌的深色 SUV。真真假
假的消息搅在一起，比鹤城春天的梅雨还黏糊。警察守口如瓶，
官方通报永远只有"正在进一步调查中"。

但你总觉得哪里不对。

你点开"鹤搜"，把论坛里看到的关键词一个个丢进搜索框。鹤城
新闻网的社会版、本地生活通上的店铺点评、甚至那些无人问津
的个人主页——碎片散落在互联网的角落里，等着有人把它们拼
起来。你在帖子里标记可疑的句子，把截图丢进线索板，像捡垃
圾一样攒着别人不屑一顾的细节。

慢慢地，一些东西浮出水面。

山茶花粉。42 码鞋印。薄荷味的黑色口罩。18 天一次的周期。
还有那个在监控里永远低着头、操着本地口音、身高一米七八的
男人——他三次出现在酒店大堂，三次带着不同的女人离开，三
次都没有摘下口罩。

你的帖子引起了注意。

某天早上，一条私信躺在收件箱里，发件人认证信息是"鹤城市
公安局"。对方没有寒暄，只有一句话：

"你在论坛上的分析我们看到了。专案组需要你这样的人。"

你被拉进了一个线上协作平台。现场勘查记录、法医尸检报告、
物证溯源链、监控逐帧分析、犯罪心理侧写——那些只在电视剧
里见过的材料，此刻摊开在你面前。四名嫌疑人也被带到了你面
前：

  A. 张运来——山茶种植园货车司机，本地人，左手有薄茧
  B. 李文彬——社区卫生服务站医生，湖南入赘，斯文温和
  C. 赵刚——农贸市场屠宰工，刀工精湛，脾气火爆
  D. 周明——汽修厂技师，广东来的，沉默寡言

每个人都有秘密，每个人都在说谎，每个人都差那么一点"就
是他"。但凶手只有一个。物证不会说谎——花粉指向南郊，酒
精指向医疗背景，右手持刀排除左撇子，无牌 SUV 指向外地套
牌，18 天的仪式化周期指向偏执而非冲动。

而日历上，距离上一次作案，已经过去了 17 天。

没有时间了。

你坐在屏幕前，深吸一口气，点开了"最终推理"。

四个选项，一个真相。选错了，凶手会继续逍遥法外，第四个女
人可能在明天晚上消失。选对了，这三个月的噩梦才能结束。

鹤城的夜色很深。但总有人要点灯。

================================================================
  五、游戏流程概览
================================================================

1. 鹤搜首页：输入昵称，以普通网民身份进入鹤城互联网
2. 清风论坛：浏览案件讨论帖，标记可疑片段，收集第一手线索
3. 鹤城新闻 / 生活通：通过搜索引擎交叉验证信息，访问人物主页与地点
4. 线索板 & 收集箱：汇总已标记线索，梳理证据链
5. 专案组工作台：解锁后调阅五章内部侦查材料
   （现场勘查 → 法医报告 → 物证溯源 → 监控分析 → 心理侧写）
6. 嫌疑人审讯：与四名嫌疑人对话，识别证词矛盾
7. 最终推理：综合全部证据，在 A/B/C/D 中选出唯一正确答案
8. 结局页：答对则真相大白，答错可回溯线索重新推理
